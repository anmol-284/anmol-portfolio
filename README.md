# Anmol Sahu — Portfolio

Personal portfolio website built with Next.js 16, TypeScript, Tailwind CSS and Framer Motion.

**Live:** https://anmol-portfolio-iota.vercel.app

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Vercel (deployment)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

```bash
npx vercel --prod
```
